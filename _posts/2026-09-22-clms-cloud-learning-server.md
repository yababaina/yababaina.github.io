4학년 1학기에 졸업 프로젝트로 CLMS라는 학습용 클라우드 서비스를 만들었습니다. 교수님은 학생들 개발 환경을 쉽게 나눠 주고, 학생은 자기가 원하는 환경을 직접 꾸려서 쓸 수 있게 하자는 게 목표였습니다.

**팀 구성**

- 프론트엔드 2명
- 백엔드 2명
- 서버 1명 (담당)

**결과 요약**

- 교수자의 여분 컴퓨터를 **셸 스크립트 하나로 클라우드 서버로 전환**
- 학생마다 **Docker 기반 개인 인스턴스**를 만들고, 본인만 SSH로 접속할 수 있도록 구성
- 졸업 프로젝트 A+, 한국정보기술학회 대학생 논문 경진대회 **동상**

# 전체 구조

```
 ① CLMS (웹 서비스)                                  ④ 교수자 서버 (Ubuntu)
 ┌──────────────────────┐                        ┌──────────────────────────────────┐
 │ React ── Spring      │ ─⑤ SSH (22) ─────────> │ Shell Script                     │
 │            │         │                        │   (인스턴스 생성/삭제, 규칙 관리) │
 │          MySQL       │                        │                                  │
 └──────────────────────┘                        │ Nginx (80) ── 도메인별 라우팅     │
                                                 │   │                              │
 ② 외부 사용자 ────────────⑥ HTTP (80) ────────> │   ▼                              │
                                                 │ ┌────────┐┌────────┐┌────────┐   │
 ③ 학생 ─────────────────⑦ SSH ──────────────────┼>│ docker ││ docker ││ docker │   │
                                                 │ └────────┘└────────┘└────────┘   │
                                                 └──────────────────────────────────┘
```

| 구성 요소 | 역할 |
| --- | --- |
| ① CLMS | 교수자·학생이 쓰는 웹 서비스 (React, Spring, MySQL). 인스턴스 생성 요청을 받아 서버에 전달 |
| ④ 교수자 서버 | 학생 인스턴스(Docker 컨테이너)가 실제로 도는 서버 |
| ⑤ CLMS → 서버 | SSH로 서버의 셸 스크립트를 실행해 컨테이너와 방화벽 규칙을 관리 |
| ⑥ 외부 사용자 → 서버 | Nginx가 도메인에 따라 해당 컨테이너로 요청을 전달 |
| ⑦ 학생 → 컨테이너 | 학생이 자기 인스턴스에 SSH로 직접 접속 |
